# Arduino Robotics & Embedded Systems Projects

A collection of autonomous and sensor-driven robotics projects built using the Arduino platform, custom motor drivers, and various sensor modules.

## Included Projects
* **[Obstacle Avoiding Robot](./Obstacle-Avoiding-Robot)**: Autonomous 4WD navigation using ultrasonic distance scanning and servo direction control.
* **[Human Following Robot](./Human-Following-Robot)**: Multi-sensor tracking robot utilizing combined ultrasonic ranging and infrared directional detection.

## Setup Requirements
* Arduino IDE (v1.8.x or v2.x)
* Arduino Uno / compatible microcontroller
* External 5V–9V power source for DC gear motors
